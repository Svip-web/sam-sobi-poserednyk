# Сам собі посередник

Лендінг онлайн-курсу Тетяни Григор’євої про самостійну подачу документів на карту побиту через MOS.

## Структура

- `dist/index.html` — розмітка сторінки
- `dist/styles.css` — стилі й адаптивна версія
- `dist/app.js` — інтерактивність
- `dist/assets/` — оптимізовані зображення та іконки

Сайт автоматично публікується на GitHub Pages після кожного оновлення гілки `main`.
